# Bundled fonts

The native UI embeds unmodified Work Sans and Space Grotesk variable TrueType fonts with their SIL Open Font License 1.1 texts. Default egui fonts remain as glyph fallbacks. These files come from Google Fonts, independently of the Windows application extract.

Source repository: `https://github.com/google/fonts`, revision `86aced91de05cd4f96a06838124cca45be337b2b`.
